# Laravel 12 Project

Project ini menggunakan **Laravel 12** dan disusun untuk memudahkan kerja tim dengan pembagian tugas yang jelas.

---

## Teknologi yang Digunakan

- Laravel 12
- PHP 8+
- Blade Template Engine
- Tailwind CSS
- MySQL / MariaDB

---

## Panduan Penggunaan

### Struktur Folder

Struktur folder project dibagi berdasarkan role pengguna agar pengembangan lebih rapi dan terorganisir.


laravel-12/
├── app/
│   └── Http/
│       └── Controllers/
│           ├── Admin/
│           └── Mahasiswa/
│
├── resources/
│   └── views/
│       ├── admin/
│       └── mahasiswa/
│
└── routes/
    └── web.php
